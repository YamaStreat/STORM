# STØRM // PVP — Legal Pages

Site statique prêt pour GitHub Pages.

## Publication sur GitHub Pages

1. Crée un dépôt GitHub, par exemple `storm-pvp-legal`.
2. Ajoute `index.html`, `terms.html`, `privacy.html` et `style.css` à la racine du dépôt.
3. Sur GitHub : **Settings → Pages**.
4. Dans **Build and deployment**, sélectionne **Deploy from a branch**.
5. Choisis la branche **main** et le dossier **/(root)**, puis **Save**.

Si ton nom GitHub est `TON-PSEUDO` et ton dépôt `storm-pvp-legal`, les URLs seront :

- Conditions d'utilisation : `https://TON-PSEUDO.github.io/storm-pvp-legal/terms.html`
- Politique de confidentialité : `https://TON-PSEUDO.github.io/storm-pvp-legal/privacy.html`

Ces deux URLs peuvent être copiées dans les champs de ton application.
